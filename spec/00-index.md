# loop CLI Specification

`loop` is a Go-based AI coding harness CLI. It repeatedly runs an external coding agent against one Markdown instruction file, records each iteration, creates validated commits for complete units of work, and integrates each iteration into the base branch.

The specification defines what to implement. It does not include source comparisons, benchmark notes, or project commentary.

## Default behavior

- The default agent is `codex`.
- All generated prompts, plans, summaries, commit messages, memory files, and the default skill use English. Pull request titles and bodies follow the repository pull request template language when a template is present; otherwise they use English.
- Runs are fully automated. The agent and CLI proceed without user questions or manual user actions.
- Agents write `plan` and `todo` artifacts before repository edits, then record assumptions or return `blocked` when no safe path exists.
- Language and workflow details remain customizable through `.loop/config.yaml`, repository skills, and the user-owned Markdown instruction file.
- The compact skill bootstrap is generated by the Go implementation. User instruction files are task input only and must not be used as a substitute for system-level loop behavior.

## Primary command shape

```bash
loop init
loop run path/to/instruction.md --goal "The target behavior is implemented and verified"
```

The instruction Markdown is user-authored task input and is read at every iteration through the `instruction` artifact. The CLI injects a compact, non-user-editable skill bootstrap from code. The optional goal is evaluated by the agent at the end of every iteration through `should_fully_stop` in the result JSON.
